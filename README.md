# Zydeco

A simple, single-purpose app: search YouTube for existing channel names.

## Usage

1. Open `index.html` in a browser (no build step, no server required).
2. Paste a free [YouTube Data API v3 key](https://console.cloud.google.com/apis/credentials) into the API key field (saved locally in your browser only).
3. Type a channel name into the search box and press **Search**.

Matching channels are listed with their thumbnail, name, and description — click any result to open it on YouTube.
